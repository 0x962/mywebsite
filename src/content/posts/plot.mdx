A living wishlist for SuperSet and Conductor — the parallel-agent tools I run all
day. It grows as I think of things. Four so far.

**01 — the diff is the conversation.** Every tool puts the chat in the middle and
hides the diff in a panel. Backwards. Put the diff in the center and let me talk
to the agent by writing on it. How urgent a comment is gets set by a slash:
`/now` interrupts the run, `/btw` drops onto the to-do list, `/rule` saves it as a
reusable command.

**02 — show your work.** Flip the same diff into plain English, and put a reason
on every edit. Make the Edit tool refuse to run without one. I trust the agent's
syntax. Its judgment, not yet. So make it show its work, and I'll catch the bad
call by reading the behaviour instead of the code.

**03 — git for context.** Right now context dies with the chat window. Tie it to
the project instead. Start from a base, fork to try something, resume or drop it,
rewind to any earlier point.

**04 — where's my to-do list?** The agent keeps one in its head. Show it to me. Let
me reorder it and cross things off. Half of it is the `/btw` notes I left on the
diff.

*Four so far. The list keeps growing.*
